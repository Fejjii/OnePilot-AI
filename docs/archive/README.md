# Documentation Archive

This directory contains historical implementation notes and superseded planning material that was previously stored at repository root or alongside active documentation.

These files are preserved for engineering provenance and debugging history. They are not the current source of truth for product behavior, architecture, deployment state, or reviewer claims.

For current information, use:

1. The repository root `README.md`.
2. `docs/architecture.md`.
3. `docs/capabilities.md`.
4. `docs/evaluation.md`.
5. `docs/security.md`.
6. `docs/agent/CLOUD_HANDOFF.md` for current cloud development state.

Archived implementation summaries may describe intermediate test counts, provider behavior, architecture decisions, or bugs that were later changed.
